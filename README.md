# QuickKart – E-Commerce Frontend

QuickKart is a responsive e-commerce frontend application built with React, Redux Toolkit, and Tailwind CSS. It provides a modern shopping experience with dynamic product displays, cart management, and seamless state handling.

## Features

* Browse products with an intuitive user interface
* Add and remove items from the cart
* Update product quantities in the cart
* Global state management using Redux Toolkit
* Responsive design for mobile, tablet, and desktop devices
* Clean and modern user interface
* Fast performance with React

## Tech Stack

* React.js
* Redux Toolkit
* Tailwind CSS

## Live Demo

https://quickkart-store.netlify.app 

## Installation

1. Clone the repository

```bash
git clone <repository-url>
```

2. Install dependencies

```bash
npm install
```

3. Start the development server

```bash
npm run dev
```
